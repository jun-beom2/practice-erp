# 연습용 ERP (사내 ERP 흉내) — F12·자동화 연습용

> ⚠️ **연습용 가짜 ERP입니다.** 거래처·품번·수량은 전부 가상·더미 — 실제 회사 데이터가 아닙니다. 그래서 캡처·저장 다 마음껏 해도 안전합니다.

블록 ②③에서 **F12로 응답 보기 → 자동화(조회 → 입력 → 저장 직전 멈춤)** 를 안전하게 연습하는 사이트입니다.
(블록 ①의 F12 기초는 네이버 같은 익숙한 사이트에서, 블록 ④는 진짜 ERP에서.)

## 여는 법 — 반드시 로컬 서버로
F12 Network에 응답이 보이려면 **로컬 서버**로 열어야 합니다. (더블클릭 `file://` 로 열면 데이터가 안 옵니다.)

- Codex에: **"이 연습ERP 폴더에서 로컬 서버 열어줘"**
- 또는 터미널에서 이 폴더로 이동 후 `python -m http.server 8000` → 브라우저에서 `http://localhost:8000/`

## 화면
- `index.html` — **발주조회**: [발주조회] 버튼 → 서버에서 `api/orders.json`을 받아 표로 표시. (F12 → Network → `orders.json` → Response)
- `input.html` — **납품입력**: 발주 하나 골라 납품수량 입력 → [저장]. (자동화는 '저장' 직전에서 멈추기 연습)

## 이 사이트로 익히는 핵심 흐름
1. **F12로 응답 보기** — `orders.json`이 어떤 데이터인지 눈으로 확인 (정리표 = JSON).
2. **프록시(심부름꾼)로 응답 가져오기** — 그 주소로 대신 다녀와 데이터를 받아옴 (8회 로컬 서버 역할).
3. **RPA(로봇 손)처럼 화면 구동** — 조회·납품수량 입력을 사람처럼. **저장 직전 멈춤.**

## 안전
- 전부 가상 데이터라 **저장까지 눌러봐도 안전**합니다. 마음껏 연습하세요.
- 단, 블록 ④ **진짜 ERP**에서는 입력값을 테스트·더미로, **저장은 사람이 확인 후** 직접.
